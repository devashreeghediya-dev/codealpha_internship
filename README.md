# Data Analysis Internship

This repository contains three tasks:

## Task 1 - Web Scraping

Collected quotes and authors from a public website using BeautifulSoup.

## Task 2 - Exploratory Data Analysis

Performed basic data analysis on employee salary data.

## Task 3 - Data Visualization

Created a salary comparison chart using Matplotlib.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Requests
- BeautifulSoup

## How to Run

Install packages:

pip install -r requirements.txt

Run Task 1:

python scraper.py

Run Task 2:

python eda.py

Run Task 3:

python visualize.py
